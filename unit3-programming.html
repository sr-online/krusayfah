🔗 หน่วยที่ 3: ลิงก์และรูปภาพ

โปรแกรมเบื้องต้น 1 • มัธยมศึกษาปีที่ 2 • ภาคเรียนที่ 1/2569

ตัวชี้วัด: ใช้แท็ก HTML สร้างไฮเปอร์ลิงก์เชื่อมโยงหน้าเว็บและใส่รูปภาพประกอบเนื้อหา เข้าใจเส้นทางไฟล์แบบสัมพัทธ์และสัมบูรณ์ (ว. 4.2 ม. 2/1-2/2)
1

ไฮเปอร์ลิงก์ (Hyperlink)

แท็ก <a>

ใช้สร้างลิงก์เชื่อมโยงไปยังหน้าเว็บอื่น เว็บไซต์อื่น หรือไฟล์อื่น ต้องมี attribute href (Hypertext REFerence) ระบุปลายทาง

<a href="https://www.google.com">ไปที่ Google</a>

แอตทริบิวต์ target

กำหนดว่าจะเปิดลิงก์ที่หน้าต่าง/แท็บไหน

ค่าความหมาย
target="_self"เปิดในแท็บเดิม (ค่าเริ่มต้น ถ้าไม่ใส่)
target="_blank"เปิดในแท็บใหม่
<a href="https://www.google.com" target="_blank">เปิดแท็บใหม่</a>

ลิงก์ไปหน้าเว็บอื่นในเว็บไซต์เดียวกัน

ถ้าลิงก์ไปหาไฟล์ในโฟลเดอร์เดียวกัน ให้ใส่แค่ชื่อไฟล์ ไม่ต้องใส่ที่อยู่เต็ม

<a href="about.html">หน้าเกี่ยวกับฉัน</a> <a href="index.html">กลับหน้าแรก</a>
2

การใส่รูปภาพ

แท็ก <img>

ใช้แสดงรูปภาพบนหน้าเว็บ เป็นแท็กที่ไม่มีแท็กปิด (self-closing) ต้องมี attribute src (SouRCe) ระบุตำแหน่งไฟล์ภาพ

Attributeหน้าที่
srcที่อยู่ของไฟล์รูปภาพ (จำเป็นต้องมี)
altข้อความอธิบายรูป แสดงกรณีโหลดรูปไม่ได้ และช่วยผู้พิการทางสายตา (จำเป็นต้องมี)
width / heightกำหนดความกว้าง/สูงของรูป (หน่วยพิกเซล)
<img src="https://picsum.photos/id/237/300/200" alt="รูปสุนัขสีดำ" width="300">

alt สำคัญมาก อย่าลืมใส่!

  • ถ้าอินเทอร์เน็ตช้าหรือลิงก์รูปเสีย เบราว์เซอร์จะแสดงข้อความใน alt แทน
  • โปรแกรมอ่านหน้าจอสำหรับผู้พิการทางสายตาจะอ่านค่าใน alt ให้ฟัง

รูปภาพจากไฟล์ในเครื่อง (เมื่อทำงานจริงใน VS Code)

เมื่อนักเรียนทำงานจริงในคอมพิวเตอร์ ควรสร้างโฟลเดอร์ชื่อ images เก็บไฟล์รูปไว้ แล้วอ้างอิงแบบนี้:

<img src="images/profile.jpg" alt="รูปโปรไฟล์ของฉัน">

(ในแบบฝึกหัดออนไลน์นี้ เราจะใช้รูปจากลิงก์อินเทอร์เน็ตแทน เพราะพรีวิวไม่สามารถเข้าถึงไฟล์ในเครื่องได้)

3

ลิงก์ภายในหน้าเดียวกัน (Anchor)

การเชื่อมโยงไปยังจุดหนึ่งในหน้าเดียวกัน

ใช้เมื่อหน้าเว็บยาวมาก แล้วต้องการทำ "เมนูลัด" ให้กระโดดไปยังหัวข้อที่ต้องการทันที ทำได้ 2 ขั้นตอน:

  • 1
    ตั้งชื่อ id ให้กับอิลิเมนต์ปลายทางที่ต้องการกระโดดไปหา
  • 2
    สร้างลิงก์โดยใส่ href="#ชื่อid" (มีเครื่องหมาย # นำหน้า)
<!-- เมนูลัดด้านบน --> <a href="#hobby">ไปที่งานอดิเรก</a> <!-- ... เนื้อหายาว ๆ ... --> <h2 id="hobby">งานอดิเรก</h2> <p>ฉันชอบเล่นกีฬาและอ่านหนังสือ</p>

เกร็ดความรู้

แท็บ "แบบฝึกหัด" ↔ "เนื้อหาบทเรียน" และเมนู "เข้าสู่บทเรียน" ที่นักเรียนใช้อยู่ในเว็บนี้ ก็ใช้หลักการ id + href="#..." คล้ายกันเลย!

4

โฟลเดอร์และเส้นทางไฟล์เบื้องต้น

โครงสร้างโฟลเดอร์เว็บไซต์ตัวอย่าง

📁 my-website/ ├── 📄 index.html ├── 📄 about.html └── 📁 images/ ├── 🖼️ profile.jpg └── 🖼️ logo.png

Relative Path (เส้นทางสัมพัทธ์)

อ้างอิงจากตำแหน่งไฟล์ปัจจุบัน นิยมใช้มากที่สุดเมื่อไฟล์อยู่ในเว็บไซต์เดียวกัน

เขียนแบบนี้ความหมาย
images/profile.jpgไฟล์ profile.jpg ในโฟลเดอร์ images ที่อยู่ระดับเดียวกัน
about.htmlไฟล์ about.html ที่อยู่โฟลเดอร์เดียวกันกับไฟล์ปัจจุบัน
../index.html../ หมายถึงถอยกลับไปโฟลเดอร์แม่ 1 ชั้น

Absolute Path (เส้นทางสัมบูรณ์)

คือที่อยู่เต็มรูปแบบ เริ่มต้นด้วย https:// ใช้เมื่อลิงก์ไปยังเว็บไซต์อื่นที่ไม่ใช่ของเราเอง

<a href="https://www.youtube.com">YouTube</a>

ลองเขียนโค้ดได้ทันทีที่นี่!

แบบฝึกหัดบทที่ 3 — เว็บแนะนำสถานที่ท่องเที่ยว

สร้างหน้าเว็บแนะนำสถานที่ท่องเที่ยวที่มีทั้งรูปภาพและลิงก์เชื่อมโยง

10 คะแนน เปิดรับงาน

โจทย์

เขียนหน้าเว็บแนะนำสถานที่ท่องเที่ยวที่นักเรียนชื่นชอบ โดยต้องมี:

  • <h1> ชื่อสถานที่ท่องเที่ยว
  • รูปภาพอย่างน้อย 1 รูป (ใช้ <img> พร้อม alt) — ใช้ลิงก์รูปจากอินเทอร์เน็ตได้ เช่น https://picsum.photos/400/250
  • ย่อหน้าบรรยายสถานที่อย่างน้อย 1 ย่อหน้า
  • ลิงก์ <a> ออกไปยังเว็บไซต์ข้อมูลเพิ่มเติม (เปิดแท็บใหม่ด้วย target="_blank")
  • ลิงก์ภายในหน้าเดียวกัน (Anchor) อย่างน้อย 1 จุด
