อินเทอร์เน็ตและเว็บไซต์ทำงานอย่างไร

เว็บไซต์คืออะไร

เว็บไซต์ (Website) คือกลุ่มของหน้าเว็บเพจ (Web Page) ที่เก็บอยู่บนเครื่องคอมพิวเตอร์ ที่เรียกว่า เว็บเซิร์ฟเวอร์ (Web Server) ซึ่งเปิดให้ผู้ใช้ทั่วโลกเข้าถึงผ่านอินเทอร์เน็ตได้ โดยใช้โปรแกรมที่เรียกว่า เว็บเบราว์เซอร์ (Web Browser) เช่น Chrome, Edge, Firefox

หลักการทำงานแบบ Client-Server

  • 1
    ผู้ใช้ (Client) พิมพ์ที่อยู่เว็บไซต์ หรือ URL ลงในเบราว์เซอร์
  • 2
    เบราว์เซอร์ส่งคำขอ (Request) ไปยังเว็บเซิร์ฟเวอร์ที่เก็บเว็บไซต์นั้น
  • 3
    เซิร์ฟเวอร์ส่งไฟล์ HTML กลับมาให้ (Response)
  • 4
    เบราว์เซอร์แปลความหมาย (Render) ไฟล์ HTML แล้วแสดงผลเป็นหน้าเว็บให้เราเห็น

URL คืออะไร

URL (Uniform Resource Locator) คือ ที่อยู่ของหน้าเว็บ แต่ละหน้าบนอินเทอร์เน็ต เช่น https://www.wikipedia.org/

ส่วนประกอบตัวอย่างความหมาย
https://โพรโทคอลวิธีการรับส่งข้อมูลอย่างปลอดภัย
www.wikipedia.orgโดเมนเนมชื่อของเว็บไซต์/เซิร์ฟเวอร์
/wiki/HTMLเส้นทาง (Path)ตำแหน่งของหน้าเว็บภายในเว็บไซต์

HTML คืออะไร

ความหมายของ HTML

HTML ย่อมาจาก HyperText Markup Language เป็นภาษามาร์กอัป (Markup Language) ที่ใช้กำหนดโครงสร้างของเนื้อหาบนหน้าเว็บ ไม่ใช่ภาษาโปรแกรมมิ่งทั่วไปที่มีการคำนวณหรือเงื่อนไข แต่ใช้ "แท็ก" (Tag) เพื่อบอกเบราว์เซอร์ว่า "ข้อความส่วนนี้คือหัวข้อ" "ส่วนนี้คือย่อหน้า" "ส่วนนี้คือรูปภาพ" เป็นต้น

  • HyperText หมายถึงข้อความที่เชื่อมโยงถึงกันได้ (ไฮเปอร์ลิงก์)
  • Markup หมายถึงการ "กำกับ" เนื้อหาด้วยแท็ก
  • Language คือภาษาที่มีกฎไวยากรณ์ของตัวเอง

ทำไมต้องเรียน HTML

  • เป็นภาษาพื้นฐานที่สุดในการสร้างเว็บไซต์ทุกเว็บบนโลก
  • เรียนรู้ง่าย ไม่ต้องใช้เครื่องมือพิเศษ เขียนแล้วเห็นผลทันที
  • เป็นพื้นฐานสำคัญก่อนต่อยอดไปเรียน CSS และ JavaScript
  • ใช้สร้างผลงาน พอร์ตโฟลิโอ หรือเว็บไซต์ส่วนตัวได้จริง
3

โครงสร้างพื้นฐานของเอกสาร HTML

เอกสาร HTML ทุกไฟล์ต้องมีโครงสร้างนี้

<!-- บอกเบราว์เซอร์ว่านี่คือเอกสาร HTML5 --> <!DOCTYPE html> <html lang="th"> <head> <!-- ข้อมูลเกี่ยวกับหน้าเว็บ ไม่แสดงบนหน้าจอ --> <meta charset="UTF-8"> <title>ชื่อหน้าเว็บของฉัน</title> </head> <body> <!-- เนื้อหาที่แสดงบนหน้าจอทั้งหมดอยู่ตรงนี้ --> <h1>สวัสดีชาวโลก!</h1> </body> </html>
ส่วนหน้าที่
<!DOCTYPE html>บอกเบราว์เซอร์ว่าเอกสารนี้เป็น HTML5 (ต้องอยู่บรรทัดแรกสุดเสมอ)
<html>...</html>แท็กหลักที่ครอบเนื้อหาทั้งหมดของเอกสาร
<head>...</head>ข้อมูลเบื้องหลังของหน้าเว็บ เช่น ชื่อหน้า, การเชื่อม CSS (ไม่แสดงในหน้าจอ)
<meta charset="UTF-8">กำหนดรหัสตัวอักษร เพื่อให้แสดงภาษาไทยได้ถูกต้อง
<title>...</title>ชื่อที่แสดงบนแท็บของเบราว์เซอร์
<body>...</body>เนื้อหาทั้งหมดที่ผู้ใช้มองเห็นบนหน้าเว็บ

ข้อควรระวัง

  • แท็กส่วนใหญ่ต้องเปิด-ปิดเป็นคู่ เช่น <body> ต้องมี </body>
  • ต้องซ้อนแท็กให้ถูกลำดับ แท็กที่เปิดทีหลังต้องปิดก่อนเสมอ
  • ตั้งชื่อไฟล์เป็นภาษาอังกฤษ ลงท้ายด้วย .html เช่น index.html
4

Tag, Element และ Attribute คืออะไร

Tag (แท็ก)

สัญลักษณ์ที่เขียนอยู่ระหว่างเครื่องหมาย < > ใช้บอกความหมายของเนื้อหา ส่วนใหญ่มาเป็นคู่ คือแท็กเปิดและแท็กปิด (แท็กปิดจะมี / นำหน้าชื่อแท็ก)

<p>นี่คือย่อหน้าหนึ่งย่อหน้า</p>

Element (อิลิเมนต์)

คือแท็กเปิด + เนื้อหาข้างใน + แท็กปิด รวมกันทั้งหมด เรียกว่า 1 อิลิเมนต์

<p> ← แท็กเปิด   สวัสดี ← เนื้อหา   </p> ← แท็กปิด

Attribute (แอตทริบิวต์)

คือข้อมูลเพิ่มเติมที่ใส่ไว้ใน "แท็กเปิด" เพื่อกำหนดคุณสมบัติพิเศษของอิลิเมนต์นั้น เขียนในรูปแบบ ชื่อแอตทริบิวต์="ค่า"

<html lang="th"> <img src="cat.jpg" alt="รูปแมว">

ในตัวอย่าง lang, src, alt คือชื่อแอตทริบิวต์ ส่วน "th", "cat.jpg", "รูปแมว" คือค่าของแอตทริบิวต์นั้น ๆ

แท็กที่ไม่ต้องมีแท็กปิด (Void / Self-closing tag)

แท็กบางตัวไม่มีเนื้อหาข้างในจึงไม่ต้องมีแท็กปิด เช่น <img>, <br>, <hr>, <meta> — จะเรียนรายละเอียดในหน่วยถัด ๆ ไป

โจทย์

เขียนไฟล์ HTML 1 หน้า ที่มีองค์ประกอบครบดังนี้:

  • มี <!DOCTYPE html>, <html>, <head>, <body> ครบถ้วน
  • <title> เป็นชื่อ-นามสกุลของนักเรียน
  • ใน <body> มี <h1> ทักทายผู้เข้าชม เช่น "สวัสดีครับ/ค่ะ ยินดีต้อนรับ"
  • มี <p> อย่างน้อย 1 ย่อหน้า แนะนำตัวเองสั้น ๆ
