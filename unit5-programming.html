ตัวชี้วัด: อธิบายหลักการทำงานของ CSS และใช้ CSS พื้นฐานตกแต่งสี ตัวอักษร และระยะห่าง ของหน้าเว็บที่เขียนด้วย HTML ได้ (ว. 4.2 ม. 2/1-2/2)
1

CSS คืออะไร และวิธีเชื่อมกับ HTML

CSS คืออะไร

CSS ย่อมาจาก Cascading Style Sheets เป็นภาษาที่ใช้กำหนดรูปลักษณ์ ของหน้าเว็บ เช่น สี ขนาดตัวอักษร ระยะห่าง ตำแหน่ง — ถ้า HTML คือ "โครงกระดูก" CSS ก็คือ "เสื้อผ้าและการแต่งหน้า" ให้หน้าเว็บ

3 วิธีเชื่อม CSS เข้ากับ HTML

วิธีลักษณะ
1. Inline CSSเขียนใน attribute style ของแท็กนั้นโดยตรง — เหมาะกับการทดลองเร็ว ๆ
2. Internal CSSเขียนรวมไว้ใน <style> ภายใน <head> — ใช้ได้ทั้งหน้า
3. External CSSเขียนแยกเป็นไฟล์ .css ต่างหาก แล้วเชื่อมด้วย <link> — เป็นวิธีที่นิยมที่สุด

ตัวอย่าง Inline CSS

<h1 style="color: green; text-align: center;">สวัสดี</h1>

ตัวอย่าง Internal CSS

<head> <style> h1 { color: green; text-align: center; } </style> </head>

ในแบบฝึกหัดออนไลน์นี้ เราจะใช้ Internal CSS เป็นหลัก เพราะเขียนไว้ในไฟล์เดียวกัน ทดสอบง่าย

ตัวอย่าง External CSS (ใช้งานจริงเมื่อทำเว็บไซต์)

// ไฟล์ style.css h1 { color: green; } <!-- ไฟล์ index.html --> <head> <link rel="stylesheet" href="style.css"> </head>
2

Selector พื้นฐาน

Selector คืออะไร

Selector คือส่วนที่บอกว่า "จะตกแต่งอิลิเมนต์ตัวไหน" ไวยากรณ์ CSS พื้นฐานคือ:

selector { property: value; }

Tag Selector

เลือกจากชื่อแท็กโดยตรง มีผลกับทุกอิลิเมนต์ที่เป็นแท็กนั้นในหน้าเว็บ

p { color: blue; }

Class Selector

ใช้ attribute class="ชื่อคลาส" ในแท็ก HTML แล้วเรียกใช้ด้วยเครื่องหมาย จุด (.) นำหน้าใน CSS — ใช้ซ้ำได้กับหลายอิลิเมนต์

<!-- HTML --> <p class="highlight">ข้อความสำคัญ</p> <p class="highlight">อีกข้อความสำคัญ</p> /* CSS */ .highlight { background-color: yellow; }

ID Selector

ใช้ attribute id="ชื่อไอดี" เรียกใช้ด้วยเครื่องหมาย ชาร์ป (#) นำหน้าใน CSS — id ต้องไม่ซ้ำกันในหน้าเดียว (ใช้ได้แค่ 1 อิลิเมนต์เท่านั้น)

<!-- HTML --> <h1 id="main-title">ชื่อเว็บไซต์</h1> /* CSS */ #main-title { color: darkgreen; }

ใช้ class หรือ id ดี

ทั่วไปแนะนำให้ใช้ class เป็นหลัก เพราะใช้ซ้ำได้หลายที่ ส่วน id เก็บไว้ใช้กับจุดที่มีแค่แห่งเดียวในหน้า เช่น หัวข้อหลักของหน้า

คุณสมบัติ CSS ยอดฮิต

คุณสมบัติที่ใช้บ่อยที่สุด

Propertyหน้าที่ตัวอย่างค่า
colorสีตัวอักษรred, #ff0000
background-colorสีพื้นหลังyellow, #fef08a
font-sizeขนาดตัวอักษร16px, 1.2rem
font-familyรูปแบบตัวอักษร (ฟอนต์)'Sarabun', sans-serif
text-alignจัดตำแหน่งข้อความleft, center, right
marginระยะห่างภายนอกขอบอิลิเมนต์10px, 1rem auto
paddingระยะห่างภายในก่อนถึงขอบอิลิเมนต์10px, 1rem 2rem
borderเส้นขอบ2px solid black
.card { color: white; background-color: #059669; font-size: 18px; text-align: center; padding: 20px; border: 2px solid #047857; }

โจทย์

เขียนหน้าเว็บที่มี <style> ใน <head> (Internal CSS) และตกแต่งให้ครบดังนี้:

  • กำหนด color และ background-color อย่างน้อย 1 จุด
  • กำหนด font-size หรือ font-family อย่างน้อย 1 จุด
  • ใช้ class selector (.ชื่อคลาส) อย่างน้อย 1 จุด
  • กำหนด margin หรือ padding อย่างน้อย 1 จุด
  • กำหนด text-align: center; ให้หัวข้ออย่างน้อย 1 จุด
