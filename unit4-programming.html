📊 หน่วยที่ 4: ตารางและฟอร์ม

โปรแกรมเบื้องต้น 1 • มัธยมศึกษาปีที่ 2 • ภาคเรียนที่ 1/2569

ตัวชี้วัด: ใช้แท็ก HTML สร้างตารางแสดงข้อมูล และสร้างแบบฟอร์มรับข้อมูลจากผู้ใช้ ได้อย่างถูกต้องตามโครงสร้าง (ว. 4.2 ม. 2/1-2/2)
1

ตาราง (Table)

โครงสร้างตารางพื้นฐาน

แท็กความหมาย
<table>ครอบตารางทั้งหมด
<tr>Table Row — 1 แถวของตาราง
<th>Table Header — หัวตาราง (ตัวหนา จัดกึ่งกลางอัตโนมัติ)
<td>Table Data — ข้อมูลในแต่ละช่อง
<table> <tr> <th>วิชา</th> <th>เวลาเรียน</th> </tr> <tr> <td>โปรแกรมเบื้องต้น</td> <td>08:30 - 09:30</td> </tr> </table>

ผลลัพธ์ที่ได้ (เบราว์เซอร์จะไม่มีเส้นขอบให้อัตโนมัติ ต้องใช้ CSS ช่วย ซึ่งจะเรียนในหน่วยถัดไป):

วิชาเวลาเรียน
โปรแกรมเบื้องต้น08:30 - 09:30
2

การรวมช่องตาราง

colspan และ rowspan

ใช้เมื่อต้องการให้ช่องหนึ่งกินพื้นที่มากกว่า 1 ช่อง

Attributeความหมาย
colspan="n"ให้ช่องนั้นกินพื้นที่ n คอลัมน์ (แนวนอน)
rowspan="n"ให้ช่องนั้นกินพื้นที่ n แถว (แนวตั้ง)
<table> <tr> <th colspan="2">ตารางเรียนวันจันทร์</th> </tr> <tr> <td>คาบ 1</td> <td>ภาษาไทย</td> </tr> </table>
ตารางเรียนวันจันทร์
คาบ 1ภาษาไทย
3

แบบฟอร์มกรอกข้อมูล (Form)

แท็ก <form>

ใช้ครอบกลุ่มช่องรับข้อมูลทั้งหมด เช่น ฟอร์มสมัครสมาชิก ฟอร์มติดต่อเรา

แท็กความหมาย
<form>ครอบฟอร์มทั้งหมด
<label>ป้ายข้อความอธิบายช่องกรอก
<input>ช่องรับข้อมูล มีหลายชนิดตาม attribute type
<button>ปุ่มกด
<form> <label>ชื่อ-นามสกุล</label> <input type="text" placeholder="กรอกชื่อของคุณ"> <label>อีเมล</label> <input type="email" placeholder="you@example.com"> <button type="button">ส่งข้อมูล</button> </form>

placeholder คืออะไร

placeholder คือข้อความจาง ๆ ที่แสดงในช่องกรอกก่อนผู้ใช้จะพิมพ์ ใช้เป็นตัวอย่าง/คำแนะนำ ไม่ใช่ค่าจริงที่จะถูกส่งไป

4

select, textarea และชนิดของ input

ชนิดของ <input> ที่ใช้บ่อย

typeลักษณะ
textช่องกรอกข้อความทั่วไป
emailช่องกรอกอีเมล (ตรวจรูปแบบ @ ให้อัตโนมัติ)
passwordช่องกรอกรหัสผ่าน (ซ่อนตัวอักษรเป็น •••)
numberช่องกรอกตัวเลข
dateเลือกวันที่จากปฏิทิน
radioปุ่มตัวเลือกวงกลม เลือกได้ทีละ 1 ข้อ (ใน name เดียวกัน)
checkboxช่องติ๊กถูก เลือกได้หลายข้อ
<p>เพศ: <input type="radio" name="gender"> ชาย <input type="radio" name="gender"> หญิง </p> <p>งานอดิเรก: <input type="checkbox"> อ่านหนังสือ <input type="checkbox"> เล่นกีฬา </p>

<select> เมนูดรอปดาวน์

<label>ระดับชั้น</label> <select> <option>มัธยมศึกษาปีที่ 1</option> <option>มัธยมศึกษาปีที่ 2</option> <option>มัธยมศึกษาปีที่ 3</option> </select>

<textarea> กล่องข้อความหลายบรรทัด

ใช้เมื่อต้องการให้ผู้ใช้พิมพ์ข้อความยาว ๆ หลายบรรทัด เช่น ความคิดเห็น

<label>ความคิดเห็น</label> <textarea rows="4" placeholder="พิมพ์ความคิดเห็นที่นี่..."></textarea>

ลองเขียนโค้ดได้ทันทีที่นี่!

แบบฝึกหัดบทที่ 4 — ตารางเรียนและฟอร์มสมัครสมาชิก

สร้างตารางแสดงตารางเรียนของตนเอง และฟอร์มสมัครสมาชิกอย่างง่าย

10 คะแนน เปิดรับงาน

โจทย์

เขียนหน้าเว็บที่มีองค์ประกอบครบดังนี้:

  • ตาราง <table> แสดงตารางเรียนอย่างน้อย 3 แถว (ไม่รวมหัวตาราง) มี <th> เป็นหัวตาราง
  • ใช้ colspan หรือ rowspan อย่างน้อย 1 จุด
  • ฟอร์ม <form> สมัครสมาชิกที่มี <input type="text"> และ <input type="email">
  • มี <select> หรือ <input type="radio"> อย่างน้อย 1 จุด
  • มีปุ่ม <button> ส่งข้อมูล
