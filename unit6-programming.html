🏆 หน่วยที่ 6: โปรเจกต์จบภาค — เว็บไซต์แนะนำตัวเอง

โปรแกรมเบื้องต้น 1 • มัธยมศึกษาปีที่ 2 • ภาคเรียนที่ 1/2569

ตัวชี้วัด: วางแผนและสร้างเว็บไซต์อย่างง่ายโดยใช้ความรู้ HTML และ CSS ที่เรียนมาทั้งหมด เพื่อนำเสนอผลงานของตนเอง (ว. 4.2 ม. 2/1-2/2)
1

วางแผนโครงสร้างเว็บไซต์ (Wireframe)

ทำไมต้องวางแผนก่อนเขียนโค้ด

Wireframe คือโครงร่างคร่าว ๆ ของหน้าเว็บ (ไม่ต้องสวย แค่ร่างด้วยมือในกระดาษก็ได้) ช่วยให้เรารู้ว่าจะจัดวางส่วนไหนตรงไหนก่อนลงมือเขียนโค้ดจริง ทำให้เขียนโค้ดได้เร็วขึ้นและไม่หลงทาง

ส่วนประกอบที่เว็บไซต์แนะนำตัวเองควรมี

  • ส่วนหัว (Header): ชื่อ-นามสกุล, รูปโปรไฟล์
  • ข้อมูลส่วนตัว: อายุ ระดับชั้น โรงเรียน
  • งานอดิเรก/ความสามารถพิเศษ: แสดงเป็นรายการ
  • ผลงาน/รูปภาพ: รูปกิจกรรมหรือผลงานที่ภูมิใจ
  • ช่องทางติดต่อ: ลิงก์ social media หรือฟอร์มติดต่อ

ตัวอย่างการร่าง Wireframe อย่างง่าย

┌─────────────────────────────┐ │ 🖼️ ชื่อ-นามสกุล (Header) │ ├─────────────────────────────┤ │ ข้อมูลส่วนตัว │ │ งานอดิเรก (รายการ) │ ├─────────────────────────────┤ │ 🖼️ 🖼️ 🖼️ ผลงาน/รูปภาพ │ ├─────────────────────────────┤ │ 📩 ช่องทางติดต่อ │ └─────────────────────────────┘
2

ลงมือสร้างเว็บไซต์แนะนำตัวเอง

ทบทวนแท็กที่เรียนมาทั้งหมด

หน่วยแท็ก/ความรู้ที่ใช้ได้ในโปรเจกต์นี้
หน่วย 1<!DOCTYPE>, <html>, <head>, <title>, <body>
หน่วย 2<h1>-<h6>, <p>, <strong>, <em>, <ul>, <ol>, <hr>
หน่วย 3<a href>, <img src alt>, anchor #id
หน่วย 4<table>, <form>, <input>
หน่วย 5<style>, color, background-color, margin, padding, class selector

เคล็ดลับการทำโปรเจกต์ให้สำเร็จ

  • เริ่มจากโครงสร้าง HTML ให้ครบก่อน ค่อยตกแต่งด้วย CSS ทีหลัง
  • ทำทีละส่วน ทดสอบดูผลลัพธ์บ่อย ๆ อย่าเขียนรวดเดียวยาว ๆ
  • ถ้าไม่รู้จะเขียนอะไร ย้อนกลับไปดูตัวอย่างโค้ดในหน่วยที่ 1-5 ได้เสมอ

ลองแก้ไขโค้ดตัวอย่างเว็บไซต์แนะนำตัวเองเต็มรูปแบบได้ที่นี่!

นี่คือตัวอย่างเว็บไซต์แนะนำตัวเองแบบเต็ม ลองแก้ไขให้เป็นของตัวเองดู หรือใช้เป็นจุดเริ่มต้นสำหรับโปรเจกต์ในแท็บ "โปรเจกต์"

Checklist ก่อนส่งงานและนำเสนอผลงาน

ตรวจสอบก่อนส่งงาน

  • มีโครงสร้าง <!DOCTYPE html>, <html>, <head>, <body> ครบถ้วน
  • <title> เป็นชื่อของนักเรียนหรือชื่อเว็บไซต์ที่มีความหมาย
  • ใช้แท็กจัดรูปแบบข้อความ (heading, paragraph, list) อย่างเหมาะสม
  • มีรูปภาพอย่างน้อย 1 รูป พร้อม alt ที่อธิบายรูปได้ถูกต้อง
  • มีลิงก์อย่างน้อย 1 ลิงก์ที่ใช้งานได้จริง
  • มี CSS ตกแต่งให้ดูเป็นระเบียบ อ่านง่าย สีไม่ตัดกันจนอ่านไม่ออก
  • ไม่มีข้อผิดพลาดโครงสร้าง เช่น ลืมปิดแท็ก หรือซ้อนแท็กผิดลำดับ

การนำเสนอผลงาน

เมื่อส่งงานแล้ว ครูจะนัดให้นักเรียนนำเสนอเว็บไซต์ของตนเองหน้าชั้นเรียนสั้น ๆ (2-3 นาที) โดยอธิบายว่าเว็บไซต์มีส่วนประกอบอะไรบ้าง และใช้แท็กอะไรในการสร้างแต่ละส่วน

โปรเจกต์จบภาค — เว็บไซต์แนะนำตัวเอง

รวมทุกความรู้ HTML และ CSS ที่เรียนมาตลอดภาคเรียน สร้างเว็บไซต์แนะนำตัวเองฉบับสมบูรณ์ของตัวเอง

30 คะแนน เปิดรับงาน

เกณฑ์การให้คะแนน (รวม 30 คะแนน)

  • โครงสร้าง HTML ถูกต้องครบถ้วน (doctype, head, body, title) — 5 คะแนน
  • การจัดรูปแบบข้อความ (heading, paragraph, list, เน้นข้อความ) — 5 คะแนน
  • ลิงก์และรูปภาพ ใช้งานได้จริง มี alt ครบ — 5 คะแนน
  • ตารางหรือฟอร์ม อย่างน้อย 1 อย่าง — 5 คะแนน
  • การตกแต่งด้วย CSS สวยงาม อ่านง่าย — 5 คะแนน
  • ความคิดสร้างสรรค์และความสมบูรณ์โดยรวม — 5 คะแนน
